# TrucoElite · Acceso a la beta

Página estática de reclutamiento: grupo → adhesión a prueba cerrada → Google Play. Sin formularios, cookies, analytics ni recolección de correos. Cada persona usa su cuenta directamente en Google. Los clics no acreditan inscripción ni instalación.

La descarga se mantiene desactivada hasta comprobar el canal cerrado activo y su enlace con una cuenta elegible. `CLOSED_BETA_AVAILABLE` en `beta.js` controla esa disponibilidad; sin JavaScript los enlaces de descarga siguen desactivados de forma conservadora.

Publicar únicamente esta carpeta en un repo independiente. Nunca publicar el repo privado del juego, configuraciones, logs o credenciales. Hosting previsto: GitHub Pages gratuito. Para probar localmente: `python3 -m http.server 5195 --bind 127.0.0.1 --directory sites/trucoelite-beta` desde el proyecto.
